# OctoAcme Project Management Docs

This repository contains the core project management process documentation for OctoAcme.

## Overview

OctoAcme follows a lightweight, cross-functional project lifecycle: initiate the work, align stakeholders, plan the delivery approach, execute in short iterations, track progress and risks, release with verification, and close with a retrospective. The team emphasizes customer value, clear ownership, iterative delivery, and measurable outcomes.

## Summary of OctoAcme Project Management Processes

The OctoAcme process starts with a clear business need and stakeholder alignment, then moves into lightweight planning with backlog prioritization, estimates, dependencies, and release milestones. During execution, work is tracked through a standard board workflow with daily updates, quality gates, and continuous monitoring of risks and metrics. Releases require verification and stakeholder communication, and each milestone concludes with a retrospective to capture learning and improve the process over time.

## Recommended Reading Order

For new contributors, the best path is to start with the overview, move through initiation and planning, then review execution and risk guidance before reading release and retrospective material. The roles and personas document helps clarify ownership throughout the lifecycle.
